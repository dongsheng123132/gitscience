🦐01 / 想问题

SciClaw 科研虾

一晚读完一个博士三个月的文献，帮你找到真正值得研究的问题。

  • 批量读论文 · 自动找研究 Gap · 给选题候选
  • 本地优先 · Karpathy Wiki 模式，不上传、不外泄
  • Claude Code / OpenClaw Skill 包，AI 当你的文献秘书
内测中 · 即将开源
🛡️02 / 查问题

PaperGuard 论文体检

给一篇 PDF 或一个机构，自动扫统计、数字、图像的疑点。

  • 统计自洽(statcheck/GRIM) + 图像查重(同图复用 / WB copy-move)
  • 机构 / 作者级撤稿核对(OpenAlex + Retraction Watch)
  • 只报「疑似」不下「定论」· MIT 开源
● 已开源
GitHub ↗ 在线体检 ↗
⑃03 / 验证问题

Experiment Fork 实验虾

把科学从「写论文」变成「提交实验」——GitScience 的内核。

  • 提交想法 → AI 拆实验方案(材料 / 步骤 / 成本 / 验证指标)
  • Fork 实验 · Pull 结果 · 数据回流 · 失败也是贡献
  • 远期接入自驱实验室(Self-Driving Lab)
